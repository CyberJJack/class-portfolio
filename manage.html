03 / PUBLISH

复制之后，怎么上线？

  1. 点击「到 GitHub 编辑」，用有仓库写入权限的账号登录，通常是 CyberJJack。
  2. 在文件编辑框里点击一次，按 ⌘ A（Windows 用 Ctrl A）全选原内容，再粘贴刚复制的完整 JSON。
  3. 点击 Commit changes…，填写说明，例如 Add Orbit Study，确认提交到 main。
  4. 在仓库的 Actions 里等 Pages 发布变绿，再刷新网站的 作品区。新增作品会出现在你选择的分类里。
封面怎么加？作品为什么没有播放？

封面先通过 GitHub 的 Add file → Upload files 上传到 assets/，提交后再在表单里填写 assets/文件名.webp。也可以填可公开访问的 HTTPS 图片网址。

新作品通过 p5.js 原链接实时播放，所以要在 p5.js 中保持公开。先用浏览器无痕窗口打开作品链接，确认没有登录也能看到。此工具不会复制 p5.js 的源码或文件。

three.js 请先把作品发布成可公开访问的 HTTPS 网页，再填写运行页地址。网页需要允许 iframe 嵌入才能在卡片和详情中播放；若托管方阻止嵌入，可使用「Open original」打开原网页。这个工具只添加链接和作品资料，不会替你上传 three.js 项目的模型、贴图或代码。

每次加作品前先重新打开本页面，等「现有作品已读取」出现后再添加。如果加载失败，请先检查文件；不要用空数组覆盖已有资料。
